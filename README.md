# 项目七：记忆翻牌游戏（含进阶挑战）

## 一、项目简介

一个在电脑和手机浏览器上都能玩的记忆翻牌小游戏：16 张（或更多）卡片背面朝上，每次翻开两张，寻找相同图案。全部配对成功即通关。

- **基础要求**：16 张卡片组成 8 对图案；每次最多翻开两张未匹配卡片；匹配成功保留、失败自动翻回；显示操作次数、用时和完成提示；支持随机洗牌和重新开始。
- **进阶挑战**：增加难度选择（简单 4×4、中等 6×4、困难 8×4）和当前浏览器的最佳成绩记录（按难度分别记录最少步数与最短用时，刷新后仍保留）。

## 二、文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏本体（单文件，HTML + CSS + JS 全部内联，不依赖任何外部资源） |
| `server.ps1` | Windows 免安装启动脚本（用系统自带的 PowerShell 运行，不需要装 Python） |
| `双击我启动.bat` | Windows 下双击即可启动服务的入口文件 |

技术实现要点：纯 HTML/CSS/JavaScript，无框架、无外部 CDN、无登录、无云数据库；数据保存在浏览器 `localStorage`（key: `memory-game-best-v1`），手机与电脑的本地存储相互独立、不自动同步。

## 三、运行说明

### 1. 电脑启动方式

**方案 A：Windows 免安装（推荐，不需要装任何软件）**

1. 把 `index.html`、`server.ps1`、`双击我启动.bat` 三个文件放在同一个文件夹（例如 `memory-game`）。
2. 双击 `双击我启动.bat`，弹出窗口会显示"记忆翻牌游戏服务已启动"和手机访问地址。
3. 保持这个窗口开着（关闭窗口即停止服务）。
4. 如果提示权限不足，右键 `双击我启动.bat`，选择"以管理员身份运行"。

**方案 B：安装 Python 后使用命令行**（Windows 也可用 `python` 命令）

在作品目录执行：

```bash
python -m http.server 8000 --bind 0.0.0.0
```

- `--bind 0.0.0.0` 表示监听所有网卡，手机才能访问。
- 服务启动后，本机浏览器打开 `http://127.0.0.1:8000` 即可测试。

> 防火墙提示：手机连不上时**不要关闭防火墙**。第一次启动若弹出"Windows 安全中心警报"，勾选"允许访问"；或到"Windows Defender 防火墙 → 允许应用通过防火墙"中勾选 Windows PowerShell（专用网络）。

### 2. 手机访问步骤

1. 电脑和手机连接到**同一个 Wi-Fi**（校园网禁止设备互访时，可改用允许设备互访的个人热点）。
2. 在电脑上查看本机局域网 IP（Windows：`ipconfig`；macOS/Linux：`ip addr`），例如 `192.168.1.23`。
3. 手机浏览器直接访问完整地址：`http://<电脑局域网IP>:8000`。
4. 手机不需要安装任何 App，页面会自动适配手机屏幕；期间电脑需保持开机、服务不能关闭。

### 3. 停止服务方法

- **方案 A（Windows 免安装）**：直接关闭 `双击我启动.bat` 弹出的那个黑色窗口。
- **方案 B（命令行）**：在运行服务的终端按 `Ctrl + C` 停止。

## 五、迭代记录（两轮）

### 第 1 轮：基础版本

- **提出的问题**：先做一个最小可用版本——16 张卡、8 对图案、每次最多翻两张、匹配保留/失败翻回、步数与计时、洗牌与重开。
- **修改要求**：动画期间要锁定点击，防止快速连点三张破坏规则；计时用真实时间差计算，切后台回来不偏差。
- **修改结果**：完成基础版。自检（页面脚本检查）发现两个待改进项：① 手机端副标题、底部提示字号偏小（13.6px / 12.5px，低于建议的 14px）；② 尚未实现进阶挑战。

### 第 2 轮：适配修正 + 进阶挑战

- **提出的问题**：手机端小字号影响可读性；进阶挑战（难度选择 + 最佳成绩）还未做。
- **修改要求**：移动端副标题与底部提示调至 14px；增加简单/中等/困难三档难度；按难度记录最佳成绩并写入 localStorage，通关时提示是否新纪录。
- **修改结果**：字号修正完成；难度切换（含困难 8×4 共 32 张）实测正常；通关实测 8 步完成，弹窗显示"新纪录"，localStorage 正确写入 `{"easy":{"moves":8,"seconds":4}}`，刷新后最佳成绩保留。
